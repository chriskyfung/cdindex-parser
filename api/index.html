    API Reference

    The public API of cdindex2-parser is documented below. All types are frozen dataclasses and all functions are pure where possible.

    Core API

    parse_catalog(input_path, *, encoding='utf-16')

    Parse a .IDX/.FILE pair and return a Catalog.

    Parameters

    input_path : str | Path Base name or path of the IDX/FILE pair. The suffix .IDX or .FILE is recognised; otherwise .IDX is appended. encoding : str, optional Text encoding for the input files. Defaults to "utf-16" (BOM- detected). Other common encodings such as "big5" or "cp950" may be selected if the original files use a different charset.

    Returns

    Catalog A Catalog containing the parsed entries.

    Raises

    InputNotFoundError If either the .IDX or .FILE file does not exist. LineCountMismatchError If the two files have a different number of non-empty lines. IndentMismatchError If a data line and its corresponding name line have different indentation. MalformedRecordError If any line cannot be parsed.

    Catalog(entries) dataclass

    A collection of resolved catalog entries.

    Attributes

    entries instance-attribute

    Entry(depth, name, is_dir, size_bytes, mtime, path) dataclass

    A resolved catalog entry with full path.

    Attributes

    depth instance-attribute

    is_dir instance-attribute

    mtime instance-attribute

    name instance-attribute

    path instance-attribute

    size_bytes instance-attribute

    FileRecord(indent, type, size, ts, mtime) dataclass

    A single record from a .FILE line.

    Attributes

    indent instance-attribute

    mtime instance-attribute

    size instance-attribute

    ts instance-attribute

    type instance-attribute

    NameRecord(indent, name) dataclass

    A single record from a .IDX line.

    Attributes

    indent instance-attribute

    name instance-attribute

    Utilities

    resolve_input_path(input_path)

    Convert a base path or suffixed path into (.IDX path, .FILE path).

    The old code used input_path.rstrip('.IDX').rstrip('.FILE') which treats the argument as a character set, corrupting names like MyID.IDX → My and GAME.IDX → GAM.

    This function correctly strips only the recognised suffixes and guarantees the returned pair has the same base name.

    decode_dos_datetime(ts)

    Decode a 32-bit DOS FAT timestamp into a datetime.

    Parameters

    ts : int 32-bit integer timestamp in MS-DOS FAT dosdate format.

    Returns

    datetime datetime object; 1970-01-01T00:00:00 if the timestamp is negative or the date is invalid.

    to_csv(catalog, out)

    Write a Catalog to CSV format.

    The output uses newline="" (as recommended for csv.writer on Windows) and csv.QUOTE_MINIMAL quoting.

    to_json(catalog, out)

    Write a Catalog to JSON format.

    Output schema version 1:

    .. code-block:: json

    {
  "version": 1,
  "entries": [
    {
      "path": "dir/file.txt",
      "is_dir": false,
      "size_bytes": 226,
      "mtime": "2013-11-03T14:38:30"
    }
  ]
}

    Exceptions

    All errors inherit from CDIndexError:

    CDIndexError

    Bases: Exception

    Base exception for all cdindex2-parser errors.

    InputNotFoundError

    Bases: CDIndexError, FileNotFoundError

    Raised when an input file cannot be found.

    EncodingError

    Bases: CDIndexError, UnicodeDecodeError

    Raised when the input encoding is incorrect.

    LineCountMismatchError

    Bases: CDIndexError, ValueError

    Raised when .IDX and .FILE line counts differ.

    IndentMismatchError

    Bases: CDIndexError, ValueError

    Raised when an indentation mismatch is found.

    MalformedRecordError(message, line_number=None)

    Bases: CDIndexError, ValueError

    Raised when a record cannot be parsed.

    Initialize with an optional line number for error context.

    Attributes

    line_number = line_number instance-attribute
