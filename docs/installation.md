# Installation

## From PyPI

The easiest way to install `cdindex-parser` is from the Python Package Index (PyPI).

```bash
pip install cdindex-parser
```
*(Note: This package is not yet published on PyPI. This is a placeholder for future deployment.)*

## From Source

You can clone the repository and run the script directly. This is the current recommended method.

```bash
git clone https://github.com/chriskyfung/cdindex-parser.git
cd cdindex-parser
```

There are no external dependencies required to run the `decode_cdindex.py` script.

### Requirements

- Python 3.6+
